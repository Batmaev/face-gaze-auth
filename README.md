# Лайвметр

Принцип работы:
1. Сервер генерирует случайную траекторию
2. Пользователю демонстрируется точка, которая движется по этой траектории
3. Движения глаз пользователя записываются с помощью ARKit или фронтальной камеры
4. Сервер проверяет соответствие реакции пользователя стимулу. Возвращает результат (bool), скор [0..1] и данные для отрисовки графиков.
5. При использовании ARKit на всякий случай сохраняются сырые данные о положении и ориентации устройства, глаз и головы, при использовании фронтальной камеры — исходное видео.

Предусмотрена регистрация пользователей, чтобы данные сохранялись в разные папки.

Запустить: 
1. Организовать reverse proxy / проброс портов
2. `docker compose up -d`

С GPU NVIDIA: нужны драйвер не ниже 580 и nvidia-container-toolkit, затем
`docker compose -f compose.yml -f compose.gpu.yml up -d --build`.
Без Docker: `uv sync --extra gpu` (или `--extra cpu`).

Переменные окружения бекенда:
- `TORCH_DEVICE` — устройство для UniGaze, по умолчанию `cuda`, если доступна, иначе `cpu`;
- `UNIGAZE_FP16=0` — отключить fp16 на CUDA;
- `FACE_LANDMARKER_MODEL` — путь к `face_landmarker.task`. В Docker модель уже в образе, без Docker она скачивается в `~/.cache/unified-liveness` при первом запуске. Сети из архива считаются пакетом по кадрам, без трекинга.
- `WEB_CONCURRENCY` — число процессов uvicorn. В compose стоит `2`: на 4 vCPU тестового сервера третий и четвёртый уже делят ядра на декоде видео.

Замеры: `bench_gaze.py` (пайплайн по видео) и `bench_api.py` (нагрузка на `/islive_video`).

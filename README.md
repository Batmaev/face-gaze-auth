# Лайвметр

Проверка живости по движению глаз. Пользователь следит взглядом за точкой, которая движется по случайной траектории, фронтальная камера записывает видео, а сервер сравнивает движение глаз с траекторией точки и решает, живой ли перед камерой человек.

## API

Swagger открывается на `/api/docs`. Порядок такой:

1. `GET /stim` выдаёт траекторию: кадры для показа и описание стимула `stim`.
2. Клиент показывает точку, записывает видео и отправляет его в `POST /islive_video` вместе с тем же `stim`.
3. Сервер возвращает решение, скор от 0 до 1 и данные для графиков.

Сервер ничего не помнит между запросами, поэтому `stim` хранит клиент.

## Запуск на сервере

Нужен Docker. Для GPU ещё драйвер NVIDIA 580+ и nvidia-container-toolkit.

```sh
cp .env.example .env   # вписать домен; без GPU убрать compose.gpu.yml из COMPOSE_FILE
docker compose up -d --build
```

HTTPS-сертификат Caddy получит сам. Чтобы пересобрать только один сервис: `docker compose up -d --build --no-deps backend`.

## Локальный запуск

```sh
cd backend && uv sync --extra cpu && uv run fastapi dev main.py
cd frontend && npm ci && npm run dev
```

## Данные

Каждая попытка сохраняется в `backend/data/<user_id>/attempts/`: видео и JSON со всем, что насчитал пайплайн. Логи лежат в `backend/logs`.

Скрипты для замеров скорости лежат в `backend/bench/`, как запускать, написано в начале каждого файла.
